# Roll Agent Site

Roll Agent 官网原型，使用 Next.js App Router 和静态 Agent 商店数据。

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
pnpm typecheck
```

安装命令字段保留在 `data/agents.ts` 的 `installCommand` 中，后续拿到准确 npm 接入命令后直接补齐即可。
